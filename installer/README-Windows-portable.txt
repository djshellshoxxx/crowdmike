CrowdMike @VERSION@ (beta) - Windows x64, portable

Contents
  CrowdMike.exe    standalone application (run it from anywhere)
  CrowdMike.vst3\  VST3 plug-in  -> copy the folder to C:\Program Files\Common Files\VST3
  CrowdMike.clap   CLAP plug-in  -> copy the file to C:\Program Files\Common Files\CLAP

The C++ runtime is linked statically, no redistributable is needed.
This beta is unsigned: Windows SmartScreen may warn ("More info" > "Run anyway").
Prefer the Setup installer if you want shortcuts and an uninstaller.
